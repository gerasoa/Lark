# Decisões do projeto

## ADR-001 — Nome do produto

- **Decisão:** Lark.
- **Motivo:** palavra inglesa curta, fácil de pronunciar e associada ao canto de uma ave; comunica escuta, voz e aprendizagem natural.
- **Data:** 2026-08-13.

## ADR-002 — Escopo técnico inicial

- **Decisão:** site sem login ou banco de dados na primeira versão.
- **Motivo:** validar o formato de aula e a experiência de aprendizagem antes de introduzir complexidade operacional.
- **Data:** 2026-08-13.
